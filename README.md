# Baurecht Hamburg

Was darf ich auf meinem Grundstück bauen? Die App sucht zu einer Hamburger Adresse den geltenden Bebauungsplan, das Flurstück und die wichtigsten Festsetzungen.

Öffnen: https://michelbalke.github.io/baurecht-hamburg/

Daten: Freie und Hansestadt Hamburg, LGV (Datenlizenz Deutschland – Namensnennung 2.0), Hintergrundkarte © basemap.de / BKG. Alle Angaben ohne Gewähr, verbindlich ist der Originalplan.
